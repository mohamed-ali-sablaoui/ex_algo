Comment travailler ?

Pour chaque exercice, commence par lire l'énoncé et rédige ton analyse. Ouvre ensuite la correction pour comparer ton raisonnement avec la solution proposée.

Les analyses comportent uniquement les données, les résultats et le traitement. Les solutions utilisent les structures algorithmiques de base.

Exercice 01 — Chaîne symétrique

Énoncé

Lire une chaîne non vide et déterminer si son premier et son dernier caractère sont identiques. Afficher également si la chaîne ne contient qu'un seul caractère.

Analyse

Données : ch : chaîne de caractères ; n : entier.

Résultats : Indiquer si les caractères extrêmes sont identiques ou si la chaîne contient un seul caractère.

Traitement : Calculer la longueur de la chaîne. Si elle vaut 1, traiter ce cas particulier. Sinon, comparer le premier caractère au dernier.

Afficher la solution algorithmique 
Algorithme Chaine_Symetrique
Variables
    ch : chaîne
    n : entier
Début
    Lire(ch)
    n ← longueur(ch)
    Si n = 1 Alors
        Écrire("Un seul caractère")
    Sinon
        Si ch[1] = ch[n] Alors
            Écrire("Identiques")
        Sinon
            Écrire("Différents")
        FinSi
    FinSi
Fin
Exercice 02 — Nombre entre deux limites

Énoncé

Lire trois réels a, b et x. Vérifier si x appartient à l'intervalle fermé délimité par a et b, même si l'utilisateur saisit a supérieur à b.

Analyse

Données : a, b, x : réels.

Résultats : Indiquer si x appartient à l'intervalle.

Traitement : Déterminer la borne minimale et la borne maximale, puis comparer x aux deux bornes en incluant les extrémités.

Afficher la solution algorithmique 
Algorithme Appartenance_Intervalle
Variables
    a, b, x, min, max : réel
Début
    Lire(a, b, x)
    Si a < b Alors
        min ← a
        max ← b
    Sinon
        min ← b
        max ← a
    FinSi
    Si x >= min ET x <= max Alors
        Écrire("Appartient")
    Sinon
        Écrire("N'appartient pas")
    FinSi
Fin
Exercice 03 — Chiffres pairs et impairs

Énoncé

Lire un entier strictement positif, puis compter ses chiffres pairs et impairs et calculer la somme de ses chiffres. Le nombre ne doit pas être converti en chaîne.

Analyse

Données : n : entier positif ; chiffre : entier.

Résultats : Le nombre de chiffres pairs, le nombre de chiffres impairs et la somme des chiffres.

Traitement : Extraire le dernier chiffre par MOD 10, le classer selon sa parité, l'ajouter à la somme, puis supprimer ce chiffre avec DIV 10. Répéter jusqu'à ce que n devienne nul.

Afficher la solution algorithmique 
Algorithme Chiffres
Variables
    n, chiffre, pairs, impairs, somme : entier
Début
    Lire(n)
    pairs ← 0
    impairs ← 0
    somme ← 0
    Répéter
        chiffre ← n MOD 10
        Si chiffre MOD 2 = 0 Alors
            pairs ← pairs + 1
        Sinon
            impairs ← impairs + 1
        FinSi
        somme ← somme + chiffre
        n ← n DIV 10
    Jusqu'à n = 0
    Écrire(pairs, impairs, somme)
Fin

Énoncé

Analyse

Données : A, B, C : booléens.

Traitement : Examiner les trois combinaisons possibles dans lesquelles deux valeurs sont vraies et la troisième est fausse. Réunir ces cas par OU.

Afficher la solution algorithmique 
Algorithme Exactement_Deux
Variables
    A, B, C, resultat : booléen
Début
    Lire(A, B, C)
    resultat ← (A ET B ET NON C)
        OU (A ET NON B ET C)
        OU (NON A ET B ET C)
    Écrire(resultat)
Fin

Exercice 06 — Moyenne et décision

Énoncé

Lire trois notes réelles comprises entre 0 et 20. Calculer la moyenne et afficher « Admis » si la moyenne est au moins égale à 10 et si aucune note n'est inférieure à 5. Sinon, afficher « Non admis ».

Analyse

Données : n1, n2, n3 : réels.

Résultats : La moyenne et la décision d'admission.

Traitement : Vérifier la validité des notes, calculer leur moyenne, puis appliquer simultanément les deux conditions d'admission.

Afficher la solution algorithmique 
Algorithme Decision_Notes
Variables
    n1, n2, n3, m : réel
Début
    Lire(n1, n2, n3)
    Si n1 < 0 OU n1 > 20 OU
       n2 < 0 OU n2 > 20 OU
       n3 < 0 OU n3 > 20 Alors
        Écrire("Notes invalides")
    Sinon
        m ← (n1 + n2 + n3) / 3
        Écrire("Moyenne :", m)
        Si m >= 10 ET n1 >= 5 ET
           n2 >= 5 ET n3 >= 5 Alors
            Écrire("Admis")
        Sinon
            Écrire("Non admis")
        FinSi
    FinSi
Fin
Exercice 07 — Entier palindrome

Énoncé

Lire un entier positif et vérifier s'il se lit de la même manière de gauche à droite et de droite à gauche, sans le convertir en chaîne.

Analyse

Données : n, original, inverse, chiffre : entiers.

Résultats : Indiquer si l'entier est un palindrome.

Traitement : Conserver le nombre original. Construire son inverse en extrayant chaque chiffre et en ajoutant ce chiffre à droite de l'inverse déjà construit. Comparer les deux nombres.

Afficher la solution algorithmique 
Algorithme Palindrome_Entier
Variables
    n, original, inverse, chiffre : entier
Début
    Lire(n)
    original ← n
    inverse ← 0
    TantQue n > 0 Faire
        chiffre ← n MOD 10
        inverse ← inverse * 10 + chiffre
        n ← n DIV 10
    FinTantQue
    Si original = inverse Alors
        Écrire("Palindrome")
    Sinon
        Écrire("Non palindrome")
    FinSi
Fin

Exercice 09 — Supprimer les espaces extérieurs

Énoncé

Lire une chaîne contenant éventuellement des espaces au début et à la fin. Déterminer le nombre d'espaces consécutifs au début et à la fin, sans compter les espaces situés au milieu.

Analyse

Données : ch : chaîne ; i, debut, fin : entiers.

Résultats : Le nombre d'espaces au début et à la fin.

Traitement : Parcourir depuis le début tant que le caractère est un espace. Faire de même depuis la fin. Soustraire les positions pour calculer les deux nombres.

Afficher la solution algorithmique 
Algorithme Espaces_Exterieurs
Variables
    ch : chaîne
    i, n, debut, fin : entier
Début
    Lire(ch)
    n ← longueur(ch)
    i ← 1
    TantQue i <= n ET ch[i] = " " Faire
        i ← i + 1
    FinTantQue
    debut ← i - 1
    i ← n
    TantQue i >= 1 ET ch[i] = " " Faire
        i ← i - 1
    FinTantQue
    fin ← n - i
    Écrire(debut, fin)
Fin
Exercice 10 — Réels classés

Énoncé

Lire trois réels distincts et les afficher dans l'ordre croissant, sans utiliser de tableau ni de fonction de tri.

Analyse

Données : a, b, c, temp : réels.

Résultats : Les trois valeurs dans l'ordre croissant.

Traitement : Effectuer des comparaisons successives et échanger les valeurs lorsqu'elles sont dans le mauvais ordre, jusqu'à obtenir a inférieur à b et b inférieur à c.

Afficher la solution algorithmique 
Algorithme Tri_Trois_Reels
Variables
    a, b, c, temp : réel
Début
    Lire(a, b, c)
    Si a > b Alors
        temp ← a
        a ← b
        b ← temp
    FinSi
    Si b > c Alors
        temp ← b
        b ← c
        c ← temp
    FinSi
    Si a > b Alors
        temp ← a
        a ← b
        b ← temp
    FinSi
    Écrire(a, b, c)
Fin

Exercice 12 — Suite de valeurs réelles

Énoncé

Lire dix réels. Calculer leur moyenne, compter ceux qui sont strictement supérieurs à cette moyenne et afficher le plus petit nombre saisi.

Analyse

Données : x : réel ; somme, moyenne, minimum : réels ; i, compteur : entiers.

Résultats : La moyenne, le nombre de valeurs supérieures à celle-ci et le minimum.

Traitement : Une première boucle calcule la somme et le minimum. Une seconde lecture nécessiterait de conserver les valeurs ; sans tableau, on ne peut pas comparer ensuite les dix valeurs à la moyenne. Il faut donc adapter la méthode en deux passages sur une source relisible ou accepter une autre méthode.

Afficher une solution algorithmique adaptée 
Algorithme Suite_Reels
Variables
    x, somme, moyenne, minimum : réel
    i, compteur : entier
Début
    somme ← 0
    Pour i de 1 à 10 Faire
        Lire(x)
        somme ← somme + x
        Si i = 1 OU x < minimum Alors
            minimum ← x
        FinSi
    FinPour
    moyenne ← somme / 10
    Écrire("Moyenne :", moyenne)
    Écrire("Minimum :", minimum)
    Écrire("Pour compter les valeurs supérieures, il faut
    relire les données ou les mémoriser.")
Fin

Exercice 16 — Calcul d'une facture

Énoncé

Lire le prix unitaire et la quantité d'un produit. Accorder une réduction de 10 % si le montant avant réduction est au moins égal à 500, puis calculer le montant final.

Analyse

Données : prix : réel ; qte : entier.

Résultats : Montant initial, réduction et montant final.

Traitement : Multiplier le prix par la quantité. Appliquer la réduction uniquement si le seuil est atteint, puis soustraire la réduction du montant initial.

Afficher la solution algorithmique 
Algorithme Facture
Variables
    prix, montant, reduction, final : réel
    qte : entier
Début
    Lire(prix, qte)
    montant ← prix * qte
    reduction ← 0
    Si montant >= 500 Alors
        reduction ← montant * 0.10
    FinSi
    final ← montant - reduction
    Écrire(montant, reduction, final)
Fin

Exercice 58 — Calcul de moyenne avec arrêt

Énoncé

Lire des notes comprises entre 0 et 20 jusqu'à ce que l'utilisateur saisisse -1. Calculer la moyenne des notes valides et compter les notes supérieures ou égales à 10. Si aucune note n'a été saisie, afficher un message adapté.

Analyse

Données : note, somme, moyenne : réels ; nb, admises : entiers.

Résultats : Moyenne des notes valides et nombre de notes au moins égales à 10.

Traitement : Lire les notes jusqu'à la valeur sentinelle -1. Ignorer les valeurs hors de l'intervalle 0 à 20. Accumuler la somme et les compteurs, puis calculer la moyenne si le nombre de notes valides est non nul.

Afficher la solution algorithmique 
Algorithme Moyenne_Avec_Arret
Variables
    note, somme, moyenne : réel
    nb, admises : entier
Début
    somme ← 0
    nb ← 0
    admises ← 0
    Lire(note)
    TantQue note <> -1 Faire
        Si note >= 0 ET note <= 20 Alors
            somme ← somme + note
            nb ← nb + 1
            Si note >= 10 Alors
                admises ← admises + 1
            FinSi
        FinSi
        Lire(note)
    FinTantQue
    Si nb = 0 Alors
        Écrire("Aucune note valide")
    Sinon
        moyenne ← somme / nb
        Écrire(moyenne, admises)
    FinSi
Fin
